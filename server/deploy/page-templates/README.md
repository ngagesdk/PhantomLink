# Arena page templates

This folder contains XHTML templates for every Arena device-page route documented in `server/deploy/www/README.md` and `docs/ARENA.md`, plus XML examples for the generated community lists. The templates are intentionally outside `www_root`: enabling a file at a path already generated by the server takes precedence and disables that route's live content.

To customize a route, copy its corresponding file into `www_root` at the matching path and remove the `.template` suffix. For example, copy `n-gage/device/global/play/rankings/post_game.jsp.template` to `www_root/n-gage/device/global/play/rankings/post_game.jsp`. For shared styles, keep the page's inline CSS and XHTML compatibility attributes when adapting it for the N-Gage browser.

`{{...}}` values are illustrative placeholders, not server-side substitutions. Replace them manually before serving a copied template; escape text and attribute values for XHTML/XML, and insert only valid XHTML markup where a placeholder represents a group of rows. The profile template is a layout example only; the server's generated profile is dynamic and privacy-filtered, so leave it generated unless you intentionally want a static profile page.

The `community/*_x.jsp` examples are XML list responses, not visual pages. Their live endpoints are generated dynamically by default. Routes that the framework may request but whose exact paths are not documented or implemented (for example downloads and message boards) are not guessed here; they continue to receive the server's standard fallback response.
